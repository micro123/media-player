# 独立音乐界面 0.9.0

版本 0.9.0，versionCode 9，同时包含 [播放方向设置](video-orientation-0.9.md)。

音乐使用独立的 MusicPlayerScreen，不再使用旧的通用 PlayerScreen，也不创建视频 Surface。
页面保留系统状态栏和返回浏览入口，显示封面、歌曲名、歌手、专辑、进度与时间，
提供上一首、播放/暂停、下一首、倍速、播放列表、歌曲信息和打开其他文件。
返回后可在应用内继续播放，底部迷你播放器同步显示封面与歌曲名；停止则结束播放。

## 两种布局

- 竖屏：封面在上，歌曲信息、进度和播放控制在下。
- 横屏：封面在左，信息和控制在右。控制区在空间不足时可滚动。

音乐页面不设置 Activity 的屏幕方向，不提供横竖屏切换、视频比例、视频手势或画中画按钮。
布局根据当前窗口宽高调整，跟随系统方向和分屏尺寸。

## 标签与封面

AudioMetadataRepository 使用系统 MediaMetadataRetriever 在 IO 线程读取内嵌封面和标签：
歌曲名、歌手、专辑、专辑歌手、年份、流派、曲目序号、作曲、码率。
信息弹窗同时显示文件名和播放时长。
MP3 对应 ID3 标签；其他系统支持的音频格式使用其对应的元数据。
无标签时显示文件名、未知歌手/专辑；无封面或封面无法解码时显示默认唱片封面。
读取失败不影响播放。封面最多接受 4 MiB 的编码图片，按最大 768 像素采样解码。

本地 content/file 来源及 SMB/NFS 使用统一的可定位文件描述符来源，不复制完整音频到本地。
元数据读取拥有独立句柄，完成或失败后释放，不抢占播放内核的输入句柄。
切换媒体时取消旧的元数据任务；界面按 URI 校验信息，避免把上一首的封面显示到下一首。
HTTP 流本版使用文件名和默认封面，不额外创建可能持续阻塞的流媒体标签连接。
不联网查询外部封面，不读取或导出账号密码。

测试素材 music-tags-test.mp3 是项目生成的 45 秒低音量音调，附带自绘封面及中文 ID3。
测试覆盖真实标签/封面提取、解码采样、竖横布局、音乐播放/暂停/定位、返回迷你播放器与停止。
