# 媒体播放器 0.14.0

- 音乐支持后台播放：切换应用、锁屏、关闭播放页面及移除最近任务时继续播放，视频退出即停止的规则保留。
- 应用显示名称改为「媒体播放器」，包名和已有数据保持兼容。
- 设置页底部增加关于卡片，显示应用版本、播放内核、GPL-3.0 许可和可直接打开的代码仓库入口。
- 增加系统媒体通知与媒体会话，显示封面、曲目信息、播放状态和进度，支持播放 / 暂停、切歌、进度跳转与点击返回音乐界面。
- 暂停时释放播放唤醒锁，停止时移除通知；拔出耳机暂停并沿用播放器的音频焦点处理。
- Navidrome「播放全部歌曲」读取完整音乐库或全部匹配歌曲，不受浏览分页限制；从任何一页操作都从第一首开始。
- 收集歌曲时显示进度，支持取消，失败时保留原有队列。只读取元数据，音频仍按需播放。
- 播放列表改用封面 / 缩略图卡片与专用拖拽把手，支持边缘自动滚动和无障碍上移 / 下移。
- 显示时长、格式、大小；音乐显示歌手、专辑和码率，本地视频显示分辨率。
- 增加按需预览缓存：8 MiB 内存，64 MiB / 400 项磁盘，7 天过期，可由 Android 系统设置清理应用缓存。
- 修复重复曲目导致列表键冲突和排序后播放项错误的问题，排序保留正在播放的具体位置。
- 列表页与播放列表弹层共用新交互。

浏览仍分页以减少等待；播放全部只收集元数据，不预先下载全部音频。
本地视频支持缩略图，普通 HTTP 直播及 SMB/NFS 视频保留类型图标，读取不到的媒体信息不显示。
继续提供四种 CPU 架构 APK 与 universal 通用包。

验证：

- 81 项 JVM 用例，77 项通过、4 项可选网络用例跳过；Android Lint 无错误。
- 真机验证音乐后台播放、系统媒体会话控制、移除最近任务后继续播放、通知返回和视频后台停止。
- 真机验证长队列拖拽、边缘自动滚动、无障碍排序、媒体信息与磁盘预览缓存恢复。
- Navidrome 真实服务器完整收集 1,387 首歌曲，覆盖服务器搜索、封面和原始音频播放 / 跳转。
- 回归媒体库、播放进度、倍速、方向策略、视频手势、小窗和区间录制。
- 五种 APK 均验证版本、包名、签名证书和 16 KiB 页对齐。
