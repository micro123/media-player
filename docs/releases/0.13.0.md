# Media Player 0.13.0

- 新增 Navidrome 音乐服务器：从「文件 → 添加网络位置 → Navidrome」保存服务器、用户名和密码。
- 浏览专辑、歌手、全部歌曲与服务器播放列表，支持服务器搜索及分页。
- 专辑与播放列表按服务器曲目顺序播放，分页歌曲支持播放当前页。
- 复用独立音乐界面，读取服务器封面与标题、歌手、专辑、年份、流派、曲目编号和码率。
- 原始音频流播放，支持进度跳转、倍速及播放进度记忆。
- 支持服务器与浏览位置书签，队列可收藏或导出 M3U。认证配置加密保存，历史和列表不包含密码或临时认证参数。
- 提供四个 CPU 架构 APK 与 universal 通用 APK，普通 64 位 ARM 手机选择 arm64-v8a。

服务器接入为只读，当前不包含离线下载、歌词、写入服务器收藏 / 播放列表或播放统计。
Navidrome M3U 使用本应用稳定地址格式，需要保留对应服务器配置；不适用于其他播放器。
源码下载及原生依赖重建方式见 README。

## 验证

- JVM 检查与 Android Lint 通过。
- Navidrome 自建服务器覆盖分页、搜索、认证错误、响应限制、加密书签、曲目顺序、封面、原生音频流和前后跳转。
- 实机验证真实 Navidrome 服务器的音乐库、搜索、封面、播放与跳转；账号仅临时存入设备私有目录并在测试后删除。
- Navidrome 入口 / 搜索 UI、SMB/NFS 适配器及文件管理器打开功能完成回归验证。
- 四种架构包和通用包均验证发布签名、版本与对齐；ARM64 包约 25.9 MiB。
