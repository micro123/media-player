# 媒体播放器 0.15.0

- 修复视频按 Home、切换应用以及锁屏后返回时退出到播放列表的问题。默认暂停并保留视频页面和当前位置，返回后由用户继续播放。
- 新增「离开应用时自动小窗」开关。开启后，正在播放的视频离开应用时自动进入系统画中画；无法进入小窗时按后台播放设置处理。
- 新增「视频后台播放」开关。不使用小窗时也可以在切换应用或锁屏后继续播放，提供媒体通知和系统播放控制。
- 两个视频开关默认关闭，可在全局设置和视频播放设置中调整，选择全局保存。已暂停的视频保持暂停；主动返回退出视频播放页仍停止并保存进度。
- 从本地或网络目录选择媒体时生成目录播放列表。本地目录队列使用文件浏览排序，搜索筛选不缩小自动生成的队列。
- 首页新增「最近一次播放」快速回放卡片，保存最后一次播放列表、当前项和进度。仅保留最新一份记录；失效文件和离线网络位置仍保留，展示入口时不检查可用性。
- 设置页「关于」新增 GitHub 更新检查，读取最新正式 Release、比较版本、显示更新说明和发布时间。只提示更高版本，不提示降级。
- 优先选择设备对应架构 APK，缺少时使用通用包。GitHub API 限流时尝试从 Release 页读取版本和实际附件链接。
- APK 支持应用内下载，不依赖浏览器；显示进度，支持取消、失败重试和重启后恢复下载任务，下载由系统下载服务处理。
- 下载完成后检查包名、发布版本、签名兼容性和附件提供的 SHA-256。点击「安装更新」打开系统安装器，来源授权和最终安装由用户确认。

继续提供 arm64-v8a、armeabi-v7a、x86、x86_64 单架构 APK 和 universal 通用包。
正式版沿用原包名和发布签名，可覆盖更新并保留已有数据。调试版与正式版签名不同，不能直接覆盖安装。

验证覆盖版本比较、架构选择、更新错误和限流处理；真机覆盖视频后台策略、自动小窗、音乐后台播放、目录完整队列、进度恢复、离线快速回放、真实 GitHub APK 下载、任务恢复及签名不兼容拦截。
真实安全锁解锁测试未自动执行，锁屏处理逻辑另有测试。发布工作流逐一检查五个 APK 的版本、包名、签名、架构和 16 KiB 页对齐。
