# Media Player 0.12.0

## 发布与项目身份

- 正式应用 ID 统一为 `io.github.micro123.mediaplayer`，应用、播放核心与测试代码同步调整。
- 使用专用发布密钥签名，后续正式版本沿用相同密钥。
- GitHub Actions 自动执行单元测试、lint 与调试包构建；版本标签触发签名 APK 构建和 Release。
- Release 提供安装包、SHA-256 校验文件、构建信息和 R8 混淆映射。
- 更新项目首页、构建说明、发布流程及问题反馈模板。

## 播放器功能

- 安卓媒体库、前缀剧集归类、本地文件与 SMB/NFS 网络位置浏览。
- 目录名称、大小、类型升降序排序，搜索图标展开输入框。
- 独立视频与音乐界面；视频全屏，支持横屏、竖屏和保持方向。
- 0.1～5.0 倍速、全局记忆与长按临时 2 倍加速。
- 横屏左右双击快退/快进 10 秒；滑动与进度条跳转支持取消、本地画面预览及暂停后恢复。
- 同按钮开始/结束区间录制，原速无损 MP4 导出。
- M3U 播放列表、网络位置与目录书签、观看进度恢复及文件管理器「打开方式」。

## 安装说明

最低 Android 8.0，通用 APK 支持 arm64-v8a、armeabi-v7a、x86、x86_64。
本版本使用新的应用 ID，可与此前的 `com.tang.player` 测试版并存；旧版设置、书签和播放记录不会自动迁移。
当前版本提供单个通用 APK，下载后安装即可，不需要解压映射 ZIP。

源码与原生依赖来源、许可说明见仓库 `THIRD_PARTY_NOTICES.md`。
