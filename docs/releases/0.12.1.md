# Media Player 0.12.1

## 更小的安装包

- Release 按 CPU 架构提供四个独立 APK：arm64-v8a、armeabi-v7a、x86、x86_64，同时保留 universal 通用 APK。
- 普通 64 位 ARM 手机优先选择 `media-player-0.12.1-arm64-v8a.apk`；Moto X40 使用此包。
- 每个架构包都是完整安装包，选择一个安装即可，不需要安装多个 APK。
- 所有包使用相同应用 ID、版本号与发布签名，支持从 0.12.0 正式版覆盖升级。
- 保留原有 libmpv/FFmpeg 解码能力，仅去除不属于所选架构的原生库。

## 自动发布与下载

自动发布会逐个验证五个 APK 的签名、包名、版本、原生架构和对齐。
`BUILD_INFO.json` 记录每个 APK 的架构、大小和 SHA-256，`SHA256SUMS` 覆盖全部正式附件。
源码下载地址与重建步骤继续放在 README，发布流程不下载或打包原生源码。
