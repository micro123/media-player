# 媒体库自动剧集归类 0.5.0

媒体库默认开启“剧集归类”，可点击筛选区同名开关切换到普通文件列表，选择全局持久保存。
最近播放继续按原有历史记录展示，文件夹继续按实际目录展示。
归类只建立内存中的展示索引，原文件名、URI、位置及观看进度不变。
读取权限与媒体库扫描范围不变，不访问网络服务。

## 识别规则

至少两个不同 URI 的文件才建立一个剧集。标题统一全角/半角、大小写及空格/点/下划线/横线分隔符，
识别常见字幕组、分辨率、编码和校验标签，以减少这些后缀带来的拆分。

| 文件名示例 | 展示及顺序 |
| --- | --- |
| 深海回声01、深海回声2、深海回声10 | 深海回声：01 → 2 → 10 |
| 深海回声 第一集、深海回声 第2集、深海回声 第十一集 | 深海回声：第一集 → 第2集 → 第十一集 |
| Deep.Ocean.S01E02、Deep Ocean S01E10 | Deep Ocean · 第1季：E02 → E10 |
| Deep Ocean S02E01、Deep Ocean S02E02 | 单独的 Deep Ocean · 第2季 |
| [Group A] Deep Ocean - 01 [1080p HEVC]、[Group B] Deep Ocean - 02 [720p] | Deep Ocean |
| [字幕组][深海回声][01][1080p]、[字幕组][深海回声][02][720p] | 深海回声 |
| 机器学习-安装环境、机器学习-训练模型 | 机器学习，共同词语前缀归类 |

有明确标记时按季和集数识别，保留同集不同版本，不删除“重复”文件。
无集数标记时，使用分隔符边界上的共同词语前缀，并优先更长的共同名称。
例如“机器学习-基础-入门/进阶”和“机器学习-实战-入门/进阶”分成基础、实战两个系列。
短的通用词、无分隔符的零散相似字符不会触发前缀归类。
拍摄/录屏命名（VID/IMG/DSC/PXL 等）、日期型名称、仅数字或 video 等通用名称保持单独展示。
以数字开头的正常作品名（例如“86-不存在的战区”“3 Body Problem”）仍可识别，
没有媒体扩展名时也不会误删 S01E01 这样的集数标记。
音频和视频不会归入同一组，不同季分开；单文件仍直接显示文件卡片。

这是保守的文件名推断，无法从任意文件名准确推断真实作品；不可靠或不规则的名称可能保持单独文件。
本版未提供手动合并/拆分和在线剧集资料匹配。

## 浏览与播放

- 剧集卡片显示名称、文件数及自动归类提示；未归类的文件直接显示。
- 根媒体库仍支持视频/音频筛选和文件名搜索，搜索具体集名也可找到对应剧集。
- 点击剧集进入详情，显示按集数排序的完整文件名，支持搜索本剧集及播放全部。
- 点击某集构建该剧集专属队列，从该集开始；下一集沿用已有的自动下一项设置。
- 退出视频保存位置并停止，回到剧集详情；详情返回回到媒体库及先前的搜索/滚动状态。
- 关闭归类时恢复原文件列表，不改变播放列表或观看进度。

分组在媒体库刷新后于后台重新计算，组合键取规范化标题、媒体类型及季号；
新增集数不会改变有明确集数标记的剧集标识。
界面只保存选中剧集的键和少量浏览状态，不把整份媒体数据写入页面恢复 Bundle。
