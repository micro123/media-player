# 0.3.0：列表、倍速、全屏、画中画与片头片尾跳过

## 文件来源与授权

默认使用安卓 MediaStore，显示视频及音频，可筛选全部/视频/音频。
首次说明并请求“访问所有文件”，跳转本应用的系统特殊权限页；由系统开关授权，
应用通过 Environment.isExternalStorageManager() 检测，而不是把它当成普通运行时权限。
授权后“浏览文件夹”直接打开内部共享存储，可逐级浏览与返回上级；非媒体文件被过滤。
安卓对其他应用私有目录的限制仍适用。

未授予所有文件访问时，仍可单独请求音视频媒体权限；Android 14+ 的部分视频授权也会提示。
“只选文件夹”使用 OpenDocumentTree 及持久 URI 授权；“打开文件”“添加多个文件”使用 OpenDocument。
设置页提供“访问所有文件”的当前状态与管理入口。

## 播放列表

点击媒体库/文件夹中的一项，会将当前筛选列表作为队列，并从该项播放。
支持播放全部、上一项、下一项、自动下一项、多文件添加、移除、上移/下移。
列表与顺序会持久保存。自动下一项默认开启，可在列表弹层或设置关闭。
移除的是列表记录，不会删除原文件。

## 倍速与长按

范围 0.1～5.0，滑块以 0.1 为间隔；快捷选择 0.5、1.0、1.5、2.0、3.0、5.0，
并提供“恢复 1.0 倍”。“记住上次倍速”默认为关闭；开启后保存全局基础倍速，不针对文件。
关闭时本次仍维持当前速度，下次新启动默认 1.0。

长按正在播放的视频画面，临时速度 = min(基础速度 × 2, 5.0)。
例如 1.5 → 3.0、3.0 → 5.0；松手或触摸取消恢复基础速度。
暂停、切换文件、退出视频、进入画中画也会恢复。临时速度不写入全局记忆。

## 全屏、比例与手势

视频打开默认全屏；横向视频使用横向屏幕，竖向视频使用纵向屏幕。
返回键或“退出全屏”进入普通播放页，可随时再次全屏。
原始比例默认读取 mpv 的 video-params/aspect；可全局切换 4:3、16:9。
应用同步调整 Surface 尺寸与内核 video-aspect-override，采用留黑边而非裁掉画面。

- 单击：显示/隐藏控制，播放时控制在约 3.5 秒后自动隐藏。
- 双击：播放/暂停。
- 水平拖动：显示目标时间，松手后精确跳转；取消拖动不会跳转。
- 左半区纵向拖动：改变当前应用窗口亮度，退出视频时恢复窗口默认值。
- 右半区纵向拖动：改变媒体音量。
- 长按：临时倍速，并显示实际临时速度。

## 小窗与生命周期

采用 Android 系统画中画，无需悬浮窗权限。
播放视频时按 Home 自动进入，或点击“小窗”；小窗隐藏应用控制，只保留视频与系统动作。
系统播放/暂停按钮使用本应用内部广播，回到应用使用 singleTask 复用同一播放实例。
画中画保留原生播放；普通后台未进入画中画则暂停。
关闭小窗或结束 Activity 后资源释放。当前没有独立后台音频服务、通知或锁屏控制。

## 快捷跳过 OP / ED

视频控制区有独立的“跳过 N 秒”按钮，与 ±10 秒控制同时保留。
默认 N=85。设置页输入正整数秒数并“保存时长”，应用到全部视频且持久保存；可“恢复 85 秒”。
按钮标签随配置更新，从当前位置向前跳过，最大到文件结尾。文件不支持 seek 时禁用。
自动下一项开启时，跳到结尾后按同样的队列规则继续下一项。

## 观看进度

按原始 URI 保存位置和时长，每 3 秒及暂停、切换文件、释放时写入。
重新打开以 mpv start 选项从上次位置开始，控制区可“回到上次位置”或“从头播放”。
播放结束或已距结尾不足 1.5 秒时清除续播点。最多保留最近 500 个文件的进度。
当前进度以 URI 标识：移动文件或更换提供方 URI 后会作为另一条记录。
