# 0.10.0 文件管理器打开与应用图标

在文件管理器中选择音频或视频，使用「打开方式」选择「本地播放器」。视频打开全屏播放界面，按已保存的横屏、竖屏或保持设置显示；音频打开独立音乐界面，继续读取歌曲标签和内嵌封面。

应用首次启动或已经运行时均接收所选文件。外部打开建立单文件队列，更新最近播放并按原 URI 续播；不会被启动时恢复的旧列表覆盖。再次点击桌面图标只将应用带到前台，不重新载入正在播放或暂停的文件。

## 接入与授权

MainActivity 的 ACTION_VIEW / DEFAULT 过滤器接收本地 content://、file:// 音视频，注册 audio/*、video/*，兼容 application/x-matroska 和 application/ogg。地址检查拒绝缺失地址、非本地协议和非正常层级地址；文件类型优先使用来源解析结果，其次使用发送方的有效 MIME 类型。

content:// 原样传给内容解析器与播放来源解析器，利用调用方授予的单文件读取权限。外部打开不弹出首次「所有文件权限」说明，不要求先开放整个存储。支持持久授权的提供方沿用现有授权保存逻辑；只提供临时授权的文件可在当前授权有效期内播放，后续授权失效时需要从原文件管理器重新选择。

权限缺失、文件不存在或类型无法识别时显示可操作的中文提示。视频退出与离开应用时停止的行为、音乐在应用内返回浏览后的迷你播放器行为继续沿用现有实现。

入口解析位于 ExternalMediaRequest，Activity 负责首次和后续 Intent 的分发，PlayerViewModel 等待初始列表恢复后加载新文件。收到新的外部请求时替换此前尚未完成的请求；普通桌面 MAIN 启动不触发文件加载。

## 图标

原图保留在 assets/branding/app-icon-source.png，通过 tools/create-app-icons.py 生成：

- mdpi / hdpi / xhdpi / xxhdpi / xxxhdpi 普通图标与前景资源；
- 自适应图标的深蓝背景和彩色前景；
- 主题图标使用的单色圆环与播放符号。

仅清除原图外缘连通的黑色区域；内部图案保留。自适应前景缩小，使彩色圆环落在安全区域，圆形和圆角方形裁切均保留主体。预览见 screenshots/app-icon-preview-0.10.png；设备实际渲染见 screenshots/app-icon-device-0.10.png。

## 验证

测试 APK 包含独立 UID 的文件管理器模拟 Activity 和非导出、可授予 URI 读取权限的内容提供方。它在自己的私有缓存中写入生成的 MP4/MP3，仅向播放器授予对应 URI 的读取权，以验证真实的跨应用授权流程。测试未读取用户媒体；列表、最近记录和设置在测试后恢复。

覆盖冷启动视频与旧列表竞态、已运行时视频/音乐切换、歌曲标签和封面、桌面启动不重新载入、缺失授权提示、MIME 类型过滤、异常地址拒绝，以及实际安装图标的自适应类型和单色层。

构建、真机回归结果和 APK 校验值见 verification-0.10.txt；原始设备测试输出见 verification-0.10-device.txt。
