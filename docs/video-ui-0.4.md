# 应用交互与视频播放 UI 0.4.0

本版按用户补充要求调整整体流程：主导航为“媒体库 / 文件夹 / 播放列表 / 设置”，
播放页面独立于浏览页面，不再把播放器作为底部标签，也没有嵌入列表的普通视频播放状态。

点击视频直接进入全屏，隐藏主导航；全屏可以是竖屏，也可以是横屏。
默认屏幕方向跟随传感器，可全局配置为自动、竖屏、横屏；播放页的旋转按钮只切换方向。
视频显示比例与屏幕方向独立，改变 4:3/16:9 不会强制横屏。

返回或点击左上返回：先保存进度，停止内核并关闭视频页，回到原先的媒体库、文件夹或列表。
队列继续保存，文件夹路径、浏览筛选和滚动状态通过页面状态保存恢复。
下次再次打开视频从保存位置继续；退出后不保留可发声的隐藏视频播放器。
Home 离开也会停止视频；只有主动点击“小窗”才继续在系统画中画播放，关闭小窗则停止。
音频保留独立播放页和应用内迷你控制栏，可返回浏览，后台仍暂停。

依据用户提供的横屏截图重新组织视频控制。视频仍居中按原始/4:3/16:9 比例显示，
控制叠加在画面上；上下使用透明渐变遮罩，白色图标与文字、淡紫色细进度条。
应用其他页面保留原来的主题，播放弹层使用与视频一致的配色。

## 控制位置

- 左上：返回、文件名、当前文件在播放列表中的位置。
- 右上：当前时间（横屏）、显示跳过秒数的圆形快捷按钮、播放设置、更多操作。
- 右侧中部：小窗和触摸锁定。
- 底部：已播/总时长、按实际速度计算的剩余时间、进度条、播放/暂停、上一项/下一项、±10 秒、列表、比例、倍速、旋转。
- 更多操作：从头播放、回到上次位置、恢复 1.0 倍、上一项。菜单打开时不自动隐藏控件。

顶部播放设置可配置画面比例、OP/ED 跳过秒数、自动下一项、屏幕方向；这些值与应用设置页共用全局存储。
跳过时长默认 85 秒，支持恢复默认，片尾跳转限位规则保持一致。
底部倍速按钮打开原有 0.1～5.0 倍速滑块及快捷选项，临时长按倍速仍不写入全局记忆。

横向空间不足 600dp 时，底部控制分为两行，时钟隐藏、标题省略超出部分。
所有图标动作均提供中文无障碍说明，图标按钮触摸区域为 48dp。

## 锁定

锁定后隐藏顶部、底部和小窗入口，只保留解锁按钮；触摸画面会提示解锁位置。
双击、拖动和长按不再改变播放、进度、亮度、音量或倍速。
锁定不暂停播放，也不重置当前窗口亮度。
点击右侧解锁或按系统返回先解除锁定；切换文件、进入画中画也会解除锁定。
正常播放时控制约 3.5 秒自动隐藏，单击画面显隐。

## 真机验证

测试设备为 moto X40（API 36，arm64-v8a），测试媒体均为应用创建的静音视频。
新增测试覆盖锁定后的双击、拖动、长按屏蔽及解锁后的播放按钮，
以及顶部设置保存、比例切换、底部倍速弹层、旋转按钮、横竖屏控件可见范围。
流程测试覆盖返回原列表、停止后的续播、Home 停止、主动小窗、音频迷你控制栏。
横竖屏截图仅使用测试自己的媒体，在应用缓存内生成，再导出用于界面检查。

2026-10-07，完整真机回归 **OK (16 tests)**，耗时 57.515 秒。
Debug、AndroidTest、Release（R8/资源缩减）构建通过；Release 只验证构建，未签名安装。

实际截图检查发现并修复：竖屏安全区下的标题第二行裁剪，及暂停后旋转残留旧尺寸视频帧。
