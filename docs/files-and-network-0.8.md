# 文件页与网络位置 0.8.0

版本 0.8.0，versionCode 8。主导航为媒体库、文件、播放列表、书签、设置。

## 使用流程

「文件」页统一显示内部共享存储、系统文件夹选择器，以及已保存的网络位置和目录书签。
网络地址表单支持「保存书签」和「保存并连接」，也可编辑已有位置的地址与认证。
打开 SMB/NFS 位置后，目录浏览仍位于文件页，可进入子目录、搜索、刷新、返回上级。
在位置根返回时回到文件页的入口列表。播放视频后返回会停止播放，回到之前浏览的目录。

进入本地或网络目录后，点击「收藏当前目录」，填写名称保存。保存后可在文件页打开、
重命名或删除；进度时间点和播放列表继续在书签页使用，目录与位置也可从书签页打开。
普通共享存储书签记录目录 URI，打开时检查权限及目录是否存在，并恢复父级路径。
SAF 文件夹书签记录已授权 tree URI 和当前 document ID，打开时校验持久访问权限；
授权失效时需通过系统选择器重新选择目录。

网络子目录书签保存独立的加密配置，沿用原来的账号及协议参数。NFS 仍保留原始导出根，
不会把子目录当成一个新的导出调用 MOUNT。删除原网络位置不会删除另一个目录书签的配置。
删除该目录书签才移除其对应认证配置。现有 0.7 位置、播放时间点和列表书签向前兼容。

SMB/NFS 地址、协议范围、只读播放和 M3U 使用方式见 [0.7 网络位置说明](network-locations-0.7.md)。

## 本次设备上的 SMB 失败原因与处理

2026-10-07 检查已连接的 moto X40：LineageOS 23.2 / Android 16 / API 36。
系统网络策略为播放器 UID 10163 设置了 `REJECT_ALL`（262144），全局 restricted networking mode 开启。
这会在创建 socket 时产生 `ECONNREFUSED`，连接尚未到达 SMB 服务器。单纯检查 INTERNET
权限、服务器地址或局域网权限并不能发现这条系统应用联网策略。

用户明确授权后，仅通过播放器的系统应用设置开启「允许网络访问」。测试包 UID 10164
临时开启同一项进行验证，结束后恢复原来的禁止状态。未改变全局网络限制或其他应用配置。

新增错误分类区分系统网络拒绝、服务器拒绝连接、主机解析失败、超时、认证失败、共享不存在、
目录不存在和访问权限不足。系统拒绝时，目录页显示「打开应用网络设置」入口，进入该应用的
系统详情页，在「移动流量使用情况」中检查「允许网络访问」（具体文字取决于系统）。
错误提示仅显示受控说明和协议状态码，不显示底层异常中的账号、密码或私有地址。
