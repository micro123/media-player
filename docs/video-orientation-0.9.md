# 播放方向 0.9.0

版本 0.9.0，versionCode 9。全局设置与视频「播放设置」使用相同的三个选项：

- 横屏（默认）：进入视频播放界面请求横屏，可在横屏的两个方向之间按传感器翻转。
- 竖屏：进入播放界面请求竖屏，可在竖屏的两个方向之间按传感器翻转。
- 保持：不切换横竖屏，保存并保持选择该选项时当前的横竖方向。播放开始时已选择保持，
  则保留进入播放前的方向；在播放页改选保持，则保持当时的横竖方向。

这项设置持久保存并应用于所有视频。新安装、没有设置值、旧版 AUTO 或无效值使用横屏默认。
旧版明确保存的横屏或竖屏选择继续保留。退出视频播放恢复进入播放前的 Activity 方向请求，
不把视频方向限制留在媒体库或文件页。全屏、停止播放、画中画和旋转快捷按钮的流程保持一致。

「保持」记录原来的横竖方向，从小窗返回后仍使用该方向，不采纳小窗的临时窗口方向。
播放页进入时同步提交方向请求；实际屏幕旋转仍由系统处理，可能有系统旋转过渡动画。

设置页的应用版本改为读取构建版本，避免一直显示旧的 0.6.0。

验证结果见 [验证记录](verification-0.9.txt)。测试覆盖新默认和旧值兼容、三个设置选项、
横屏和竖屏进入播放、保持两种进入方向、退出后的方向恢复，以及保持横屏的画中画往返。
测试仅播放生成的视频素材，并保存、恢复原有播放设置、列表和最近记录。
